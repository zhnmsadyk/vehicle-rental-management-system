# Vehicle Rental Management System

A console-based vehicle rental system built with Python.

## Features
- View all vehicles with availability and price
- Rent and return vehicles
- Add new vehicles to the fleet
- Rental history saved with timestamps

## How to run
```bash
python main.py
```

## Project structure
- `main.py` — main menu and program loop
- `car.py` — Vehicle class (OOP)
- `rental.py` — rent/return logic with decorators
- `file_handler.py` — JSON file storage
- `decorators.py` — logging decorator
